# WellWells Homebrew tap

```sh
brew install wellwells/tap/agentswap
brew install --cask wellwells/tap/yobi
```

| Formula | Description |
|---|---|
| [agentswap](https://github.com/WellWells/agentswap) | Switch between multiple accounts of AI coding agents (`cxswap`, `ccswap`, `agswap`) |

| Cask | Description |
|---|---|
| [yobi](https://github.com/WellWells/yobi) | AI automation for the desktop that needs no AI API key (macOS 13 or later) |

Each package is updated when it is released.
