# WellWells Homebrew tap

```sh
brew install wellwells/tap/agentswap
```

| Formula | Description |
|---|---|
| [agentswap](https://github.com/WellWells/agentswap) | Switch between multiple accounts of AI coding agents (`cxswap`, `ccswap`, `agswap`) |

Formulae are updated automatically by each release.
